1. Power Distribution Network & Decoupling Architecture

CRITICAL HARDWARE RULE (COMMON GROUND & BROWNOUT PREVENT): The two SG90 barrier servos draw up to 1.6A peak current during initial rotational acceleration. They must be powered from a dedicated External 5.0V 2.0A DC Power Supply. The Ground (GND) of the external supply and the Arduino/FPGA GND MUST BE TIED TOGETHER (COMMON GROUND). A 470 µF electrolytic bulk capacitor in parallel with a 0.1 µF ceramic bypass disc across the motor rail suppresses inductive voltage droops.

4. Subsystem Electrical Schematics & Interface Calculations

A. Track Proximity Sensors (4x LM393)

Principle: 940 nm GaAs emitter + phototransistor. On-board LM393 comparator gives clean active-LOW digital logic.

  • VCC / GND: Connected to +5V Logic Rail and Common GND.
  • D0 Digital Output: Pulls to 0.0V (LOW) on train detection; sits at 5.0V (HIGH) in clear quiescent state.
  • Range Tuning: Rotate 10kΩ trimpot clockwise to increase distance (ideal: 3 cm to 5 cm from track centerline).

B. Barrier Servos (2x TowerPro SG90)

Principle: 50 Hz PWM positional control (Period T = 20.0 ms). Pulse width dictates rotational angle.

  • Vertical Position (Open 90°): 2.0 ms high pulse (50 Hz frame).
  • Horizontal Position (Closed 0°): 1.0 ms high pulse (50 Hz frame).
  • Power Rail: Red wire to External 5V 2A; Brown wire to GND.
  • Ramp Rate: ±1° step every 27.7 ms eliminates gear stress.

C. Traffic & Aspect LEDs (Current-Limiting)

Ohm's Law Calculation: R = (V_CC - V_F) / I_F = (5.0V - 2.0V) / 0.015A = 200 Ω → 220 Ω ±5%, 1/4W

  • Resistor Rating: 220 Ω, 1/4W Metal Film (Red-Red-Brown-Gold).
  • Safe Current: I_F = 13.6 mA per pin (well within 20mA limit).
  • Wiring: Resistor in series with Anode (+); Cathodes (-) to GND.

D. Push Buttons & Audible Buzzer

Pull-Down Resistor Calculation: I_closed = 5.0V / 10 kΩ = 0.5 mA (Negligible power loss)

  • Resistor: 10 kΩ, 1/4W (Brown-Black-Orange-Gold) ties pin to 0.0V.
  • Action: Pressing button injects solid 5.0V pulse without floating.
  • Active Buzzer: Pin D8 (+) to GND (-); 1.8kHz chime / 2.8kHz siren.

5. Bench Assembly & Diorama Construction Procedure

Step 1: Breadboard Power Bus Configuration

  1. Place the 830-point breadboard horizontally on your workbench. Connect the upper red power rail to the External 5V 2A DC Supply (+) and upper blue rail to External GND (-).
  2. Connect the lower red rail to the Arduino +5V pin and lower blue rail to the Arduino GND pin.
  3. TIE COMMON GROUND: Insert a heavy jumper wire connecting the upper blue rail to the lower blue rail. Both power supplies now share the same 0.0V reference potential.
  4. Insert the 470 µF electrolytic capacitor across the upper rail (Long lead = +5V, Stripe lead = GND). Insert the 0.1 µF ceramic disc capacitor (104) in parallel.

Step 2: Track Sensor Alignment & Potentiometer Calibration

  1. Mount Sensor 1 (Entry) 20 cm before the crossing on the left side of the track. Angle the IR transmitter/receiver towards the rail track at $45^\circ$.
  2. Mount Sensor 2 (Occupancy) directly in the center of the level crossing diamond facing across the rails.
  3. Mount Sensor 3 (Exit) 20 cm past the crossing on the departure side.
  4. Mount Sensor 4 (Obstacle) facing the roadway intersection to detect stalled vehicles.
  5. Calibration Routine: Power up the system. Place a toy train or wagon on the track in front of Sensor 1. Using a precision screwdriver, turn the onboard brass trimpot until the green D0 indicator LED on the sensor module lights up. Move the train away: the LED must turn off immediately. Repeat for Sensors 2, 3, and 4.

Step 3: Motorized Barrier Horn Mechanical Zeroing

  1. Connect Servo 1 signal to Pin D9 and Servo 2 signal to Pin D10.
  2. Power on the Arduino with the companion driver sketch. The firmware automatically sends a $90^\circ$ (vertical) command to both servos upon boot.
  3. Press the single-arm servo horn onto the servo spline such that the barrier arm stands vertically upright at exactly $90^\circ$. Tighten the central horn screw.
  4. Trigger Sensor 1: verify that both barrier arms rotate downward smoothly without grinding or stalling until they rest horizontally across the roadway at $0^\circ$.

const int PIN_EMG = A0, PIN_OBST = A1, PIN_TRN_G = A2, PIN_TRN_R = A3, PIN_PED_S = A5; enum FSMState { ST_OPEN = 0, ST_CLOSING = 1, ST_CLOSED = 2, ST_OPENING = 3 }; FSMState state = ST_OPEN; Servo srvN, srvS; int angle = 90; void setup() { pinMode(PIN_S1, INPUT); pinMode(PIN_S2, INPUT); pinMode(PIN_S3, INPUT); pinMode(PIN_OBST, INPUT); pinMode(PIN_EMG, INPUT); pinMode(PIN_RED, OUTPUT); pinMode(PIN_YEL, OUTPUT); srvN.attach(PIN_SRV_N); srvS.attach(PIN_SRV_S); srvN.write(90); srvS.write(90); } void loop() { bool inb = (digitalRead(PIN_S1) == LOW), occ = (digitalRead(PIN_S2) == LOW); bool out = (digitalRead(PIN_S3) == LOW), obs = (digitalRead(PIN_S4) == LOW); bool emg = (digitalRead(PIN_EMG) == HIGH), hazard = (inb || occ || obs || emg); switch (state) { case ST_OPEN: if (hazard) state = ST_CLOSING; break; case ST_CLOSING: if (angle > 0) { angle--; delay(25); } else state = ST_CLOSED; break; case ST_CLOSED: if (!hazard && out) state = ST_OPENING; break; case ST_OPENING: if (hazard) state = ST_CLOSING; else if (angle < 90) { angle++; delay(25); } else state = ST_OPEN; break; } srvN.write(angle); srvS.write(angle); digitalWrite(PIN_GRN, (state == ST_OPEN && !hazard)); digitalWrite(PIN_YEL, (state == ST_CLOSING)); digitalWrite(PIN_RED, (state == ST_CLOSED || state == ST_CLOSING || hazard)); digitalWrite(PIN_TRN_G, (state == ST_CLOSED && angle == 0 && !obs && !emg)); digitalWrite(PIN_TRN_R, !(state == ST_CLOSED && angle == 0 && !obs && !emg)); digitalWrite(PIN_PED_W, (state == ST_OPEN && !hazard)); digitalWrite(PIN_PED_S, !(state == ST_OPEN && !hazard)); if (state == ST_CLOSING || state == ST_CLOSED || hazard) { bool blink = (millis() / 400) % 2; digitalWrite(PIN_CR_L, blink); digitalWrite(PIN_CR_R, !blink); digitalWrite(PIN_BUZZ, (obs || emg) ? HIGH : blink); } else { digitalWrite(PIN_CR_L, LOW); digitalWrite(PIN_CR_R, LOW); digitalWrite(PIN_BUZZ, LOW); } }

8. Demonstration Protocol for Evaluation (40 Marks PBL)

  1. Baseline Safe Check: Power ON. Road Green ON, Pedestrian Walk ON, Barrier at 90° upright, Train Signal RED.
  2. Train Arrival Demonstration: Slide toy train past Sensor 1. Observe Road Yellow ON, Buzzer chimes, Crossbuck flashers alternate (1.25 Hz), Barrier descends smoothly from 90° to 0°.
  3. Interlock Lock Confirmation: When barrier reaches 0°, observe Train Aspect switch to GREEN (PROCEED).
  4. Departure Clearance: Move train past Sensor 3. 5-second buffer passes, barrier smoothly rises back to 90°, Road Green restored.
  5. Emergency Obstacle Injection: Place car on tracks during green signal. Sensor 4 immediately trips Train Signal RED and activates continuous emergency siren.
